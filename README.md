# The Last New Year

*Тебя ждали дома.*

Атмосферный хоррор от первого лица на Godot 4. Новогодняя ночь. Хитклифф Лоун возвращается в дом семьи, с которой давно не общался, — в заснеженную долину, куда ведёт одна лесная дорога. В доме горит одно окно, стол накрыт, но никого нет. Почти никого.

**Версия 0.2** — игра проходится от поездки к дому до заправки машины; финал в разработке.

## Что есть в игре

- **Поездка к дому от первого лица.** Ночная лесная дорога с крутыми поворотами и шпилькой, снег в свете фар. Салон машины с рабочими приборами (спидометр, тахометр, передачи, топливо, температура, контрольные лампы), часы на магнитоле, зеркало заднего вида. Руль плавно поворачивается, в поворот нужно входить самому. Бензин кончается у самого дома.
- **Дом.** Два этажа и подвал, семнадцать комнат, записки и письма семьи, детские рисунки.
- **Хранитель.** Через некоторое время после того, как за тобой захлопнется дверь, в доме появляется тот, кто тебя ждал. Он ходит по дому, слышит шаги, видит свет фонарика, открывает двери, заглядывает в шкафы.
- **Укрытия.** В шкафу смотришь наружу через щель — и надеешься, что он пройдёт мимо.
- **Головоломки.** Сейф отца с кодом с детских рисунков, запертый подвал, заколоченная дверь, ловушка с засовом.
- Ходьба, бег с выносливостью, присед, фонарик, шаги по снегу и по деревянному полу, катсцены, плавные переходы, настройки.

## Управление

| Действие | Клавиши |
|---|---|
| Ходьба / езда | W A S D или стрелки |
| Бег | Shift |
| Присесть | Ctrl |
| Прыжок / ручной тормоз | Space |
| Фонарик | F |
| Действие (взять, открыть, спрятаться) | E |
| Вид из кабины / сзади машины | C |
| Пропустить катсцену | удерживать Space или Esc |
| Пауза | Esc |
| Полный экран | F11 |

Клавиши привязаны к физическому расположению, поэтому работают на любой раскладке.

## Запуск

1. Установите [Godot 4.7.2](https://godotengine.org/download) (стандартная сборка, не .NET).
2. Откройте `project.godot` в Godot.
3. Нажмите **F5**.

Игра запускается на весь экран; F11 переключает оконный режим.

### Сборка для Windows

В редакторе: **Editor → Manage Export Templates → Download and Install**, затем **Project → Export → Windows Desktop → Export Project**. Готовый файл появится в `build/windows/`.

## Структура проекта

```
core/            автозагрузки: настройки, смена сцен, общий стиль интерфейса
gameplay/        узел игры: взаимодействие, инвентарь, сюжетные флаги, цели
player/          игрок от первого лица
characters/      Хранитель (ИИ и модель)
interactables/   двери, сейф, записки, предметы, шкафы
vehicle/         машина: вождение, салон, приборы, зеркало, камеры
cinematics/      катсцены
ui/              меню, HUD, окна, шрифты
levels/          мир (дом, лес, дорога) и сцена ритуала
audio/           фоновые звуки и эффекты
```

Все элементы интерфейса строятся кодом. Модели пока собраны из примитивов — их легко заменить: код опирается только на именованные точки-якоря внутри сцен.
